# FindIt
Sistem Informasi Barang Hilang dan Ditemukan

## Deskripsi
FindIt merupakan aplikasi berbasis web yang
digunakan untuk mencatat dan mengelola informasi
barang hilang dan ditemukan di lingkungan kampus.

## Teknologi
- PHP
- CodeIgniter 4
- MySQL
- Bootstrap 5

## Fitur
- Menampilkan data barang
- Menambahkan data barang
- Mengedit data barang
- Menghapus data barang
- Pencarian barang
- Validasi formulir
- Notifikasi

## Cara Instalasi
1. Instal XAMPP dan Composer.
2. Letakkan folder proyek di htdocs.
3. Buat database db_findit di phpMyAdmin.
4. Import file db_findit.sql.
5. Atur konfigurasi database pada file .env.
6. Jalankan aplikasi menggunakan:

   php spark serve

7. Buka http://localhost:8080

## Struktur Database
Tabel utama: barang

Kolom:
- id
- nama_barang
- lokasi
- tanggal
- deskripsi
- status
